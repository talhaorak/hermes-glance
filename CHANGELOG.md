# Changelog

User-visible changes are recorded here. Pre-1.0 compatibility may change; breaking changes should be documented explicitly.

## Unreleased — public alpha

### Added
- Independent native macOS second-monitor window, saved geometry and display controls.
- Compact Active/All/Waiting views, expanded recent events and exact-session links.
- Read-only runtime event observation at approximately one-second polling cadence.
- Explicit waiting indicators, reduced-motion support and honest disconnected state.
- Protocol/presentation tests, CI, contribution and security guidance.

### Known limitations
- Raw tool activity is not a semantic task summary.
- Selected local-profile coverage; internal Hermes runtime API dependency.
- UI is currently primarily Turkish; source builds are not notarized.
