# Community conduct

Be respectful and constructive. Discuss code and ideas, not personal attacks. Harassment, threats, discrimination, publishing private information and spam are not welcome.

Use issues and pull requests for reproducible technical discussions. Respect contributors' time; maintenance and response times are best effort.

Report conduct concerns privately through the maintainer's GitHub profile contact when available. Do not publish private reports in an issue; a public request for a private contact may omit all sensitive details.

The maintainer may remove harmful content, warn participants, lock discussions or restrict participation proportionately. This policy applies to this repository's community spaces.
